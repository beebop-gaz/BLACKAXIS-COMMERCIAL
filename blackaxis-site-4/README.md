# BLACKAXIS COMMERCIAL — Website

Official website for BlackAxis Commercial (Pty) Ltd.

## Deployment

This is a static single-page website. No build tools or dependencies required.

### GitHub Pages (recommended)
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Your site will be live at `https://yourusername.github.io/blackaxis-site`

### Custom Domain
1. Add a `CNAME` file to this repo containing your domain (e.g. `blackaxiscommercial.com`)
2. Point your domain's DNS to GitHub Pages
